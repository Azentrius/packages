Azentrius packages.

The package repository of the Azentrius add-ons for Cockpit. Set it up once; Cockpit then lists the add-ons under Applications, ready to install, and keeps them up to date with the system's own updates.

Debian and Ubuntu

curl -fsSLO https://packages.azentrius.com/azentrius-repository.deb
sudo apt install ./azentrius-repository.deb
sudo apt update

Fedora and RHEL

sudo rpm --import https://packages.azentrius.com/azentrius.asc
sudo dnf install https://packages.azentrius.com/azentrius-repository.rpm

RHEL and its derivatives use the same commands, but only Fedora is tested. openSUSE is not served: there, install the .rpm from the add-on's GitHub release.

Add-ons

  • Cron Jobs: package cockpit-cronjobs
  • Image Update Monitor: package cockpit-image-update-monitor
  • Update Gaps: package cockpit-update-gaps, Debian and Ubuntu only
  • Status Board: package cockpit-status-board, for the Cockpit host from which the others are reached

Deutsch

Das Paket-Repository der Azentrius-Erweiterungen für Cockpit. Richten Sie es einmal mit den Befehlen oben ein; danach zeigt Cockpit die Erweiterungen unter Anwendungen zur Installation an und hält sie mit den normalen Systemupdates aktuell. Jedes Paket hier hat der Release-Workflow seines eigenen GitHub-Repositorys gebaut; dieser Server prüft das, bevor er es aufnimmt.

RHEL und davon abgeleitete Systeme verwenden dieselben Befehle wie Fedora; getestet ist die Einrichtung nur unter Fedora. Für openSUSE bietet dieses Repository keine Einrichtung: Installieren Sie dort das .rpm aus dem GitHub-Release der jeweiligen Erweiterung.
